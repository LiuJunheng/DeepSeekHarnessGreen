隐私政策

最后更新：2026-09

一、我们不收集你的个人数据

DeepSeek Harness 桌面绿色整合版启动器是一个开源的绿色便携工具，运行在你的本地电脑上。它不收集、不上传、不存储任何个人身份信息（PII）。

启动器需要联网的唯一场景是：

  • 首次安装环境时下载便携 Node / Python / dsh 运行时文件
  • 启动器自身检查更新（调用 GitHub / Gitee 的公开 Release API）
  • 官方 dsh 运行时向你自己配置的 AI 模型服务发送 API 请求（完全由你控制）

以上网络请求都不附带你的个人信息，也不被第三方用于追踪。

二、发布网站与 Google AdSense

本项目的发布网站（liujunheng.github.io/DeepSeekHarnessGreen）托管在 GitHub Pages 上。

如果我们未来在本网站上启用 Google AdSense 来覆盖运营成本，你需要了解：

  • Google AdSense 可能会使用 Cookies 在你的设备上存储信息，用于展示个性化广告。
  • Google 可能会分析你访问本网站的页面、停留时间等非个人身份化的浏览数据，以决定展示哪些广告。
  • Google 的数据处理遵循 Google 隐私政策。
  • 你可以通过浏览器设置清除、禁用或限制 Cookies，也可以使用广告拦截器来阻止 AdSense 广告。

三、GitHub Pages 日志

GitHub Pages 可能自动记录访问日志（IP 地址、User-Agent、请求时间戳），用于安全和故障诊断。我们无法直接访问或修改这些日志。具体做法请参考 GitHub Pages 文档。

四、不做什么

  • 我们不会把你的数据卖给第三方。
  • 我们不会把你的数据与任何广告商共享。
  • 我们不会在启动器里植入追踪代码。
  • 我们不会要求你注册账户或提交电子邮箱。
