说明：绿色便携与“全内置整包 / 官方 CLI”是三条互补路线，没有绝对优劣。本绿色版的核心取舍是——更轻、更干净、更可迁移，聚焦 Windows 便携用户；牺牲了跨平台与代码签名等“重交付”能力。社区项目的 Guarded / 安全模式、Task Board 等亮点未刻意复刻，可按需参考移植。

社区桌面 / 整合版速览

调研 2026-09-05～09-06，star 为调研当天快照，活跃度以 Release 频率为准

dataelement/dsh-desktop

≈4244★ · Electron

社区最接近“商业成品”：六语种官网、mac 签名 + Win 代码签名、.dshpreset 预设包、手机配对、Safe Mode、诊断恢复。规格最完整。

对照本绿色版：它是更"重交付"的产品化路线，规格最完整（跨平台 + 代码签名 + 六语种官网），适合看重「商业成品级规格」的用户。

myYangyunfan/dsh_desktop

≈637★ · Tauri 2

中文功能最全的社区版：内置全套离线、守护瀑布自愈、桌面宠物 / 余额小部件、GitHub/Gitee 双源 sha256 校验更新。定位与我们最近。

本绿色版更强调“零污染 + 随包迁移”，它强调“全内置 + 桌面宠物等增强交互”。

anywhere-labs/deepseek-harness-desktop

较新·活跃

基于 Electron，社区持续跟进上游 rc；以 Cordis 插件行组合桌面能力（窗口 / 托盘 / 终端 / 更新），偏向“零 fork 跟随上游”。

跟随上游更保守，适合重视“内核原样 + 少分叉”的开发者。

citrusli2026/dsh-desktop（dsh-desktop.com）

v0.1.2-rc.1.shell.5 · macOS/Windows/Linux

官方形态新出的社区桌面壳（Electron）：“只把 Harness 带到桌面，不另做一套”。内置 Node、默认独立数据目录 ~/.dsh-desktop。

与官方命令行数据隔离、互不干扰；跨平台三端全支持。

ningbainb/deepseek-harness-desktop

v2.6.0 · Windows · BSD-3

Windows AI 编程整包：Task Board 任务看板、Git 图谱、右侧文件面板、Skills 技能库、Codex 接入，偏向“开发者工作台”。

功能堆叠更强，面向重度编程用户；体积更大、更重交付。

libi/dsh-desktop

Electron · 跟随上游

另一套 Electron/TS 桌面壳：自动拉起 DSH 后端、识别可用端口、托盘与窗口管理、跟随上游自动构建发布。结构与此类壳一致。

思路同类，整体定位与 citrusli 相近。

特色插件

全部为纯插件，不修改官方文件；安装后重启服务生效

🧠 祖宗记忆库

对话关键信息沉淀到 SQLite，下次自动召回注入 system prompt，跨会话保持记忆；支持会话分组与批量清理。

📜 用户规则注入

编写个人偏好 / 代码风格 / 沟通要求的 markdown，每次对话自动注入 system prompt。

↩️ 会话回退 / 导入

会话被工具崩溃“毒化”时回退到健康回合；会话 ZIP / JSONL 导入与官方导出互逆。

🧾 用量统计

每条消息的「本次 token / 预估费用」+ 汇总用量。

🖼️ 背景影画

本地目录视频作为 WebUI 背景播放（画面 + 声音）。

🤖 Ollama 接入

自动识别本机 Ollama 服务并接入，模型选择器直接选 Ollama 模型。
