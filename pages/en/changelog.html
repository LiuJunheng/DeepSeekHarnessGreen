New Features

  • Official sidebar-right tab type plugin (dsh-sidebar-extend): Instead of self-building a second sidebar shell, this plugin registers as a tab type provider for the official right sidebar. It takes over the official file tree with priority: "extension" (free browsing anywhere / path box / right-click @reference, edit, save-as, copy path) and adds a new text-editing tab type that the official sidebar does not have. Fold, split, float, fullscreen, and per-session layout persistence are all handled by the official container. Enabled by default.
  • launcher.defaultDisabled flag for bundled plugins: Plugins can declare "launcher": { "defaultDisabled": true } in their package.json. When the green launcher installs the plugin for the first time, it automatically adds it to the disabled list. Used by the legacy sidebar plugin (disabled by default — manual enable via Plugin Manager).

Bug Fixes

  • Modal dialog with grab_set() does not restore after minimize + taskbar click: The launcher shows modal dialogs during update checks, environment installation, etc. On Windows these dialogs swallow SC_RESTORE messages, causing the main window to stay hidden forever when the user clicks the taskbar icon. Fixed by: (1) restoring the main window before showing any modal, (2) registering each dialog and explicitly raising it, (3) wrapping the native tkinter messagebox to go through the same restore path.
  • Floating popups from dsh-file-browser / dsh-media-background overlap the official right sidebar: Fixed by reading the official data-sidebar-right-* attributes for proper offset calculation.

Technical Architecture

  • Sidebar plugin refactor: The old dsh-sidebar-lite injected a second sidebar column (portal on document.body + #root margin-right hard shift), with self-built fold/split/float logic that always conflicted with the official header, download button, and split panels. Refactored as an official right-sidebar (dsh-client-ui-sidebar-right) tab type provider: ① ctx.sidebarRightTabs.register({ kind: "files", priority: "extension" }) takes over the file tree; ② registers to sidebar.right.pane.tab slot for content injection. The official sidebar already provides browser, terminal, and preview tabs — no need to reimplement.

Version Bump

  • GREEN_VERSION: 1.0.43 → 1.0.44

Upgrade Notes

  • Green edition: overwrite install is sufficient.
  • The new sidebar plugin is enabled by default. The legacy dsh-sidebar-lite is preserved but disabled — enable manually via Plugin Manager if you want to compare.
  • Bundled plugins auto-synced to DSH 0.2.0-rc.2 core dependencies in this release.
