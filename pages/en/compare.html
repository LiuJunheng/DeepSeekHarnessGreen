Note: Green portable, all-inclusive bundles, and the official CLI are three complementary paths — none is objectively "best". The core trade-off of this green build is lighter, cleaner, more portable, focused on Windows portable users; it gives up "heavy-delivery" features like cross-platform builds and code signing. Highlights from community projects (Guarded / Safe Mode, Task Board, etc.) are not replicated on purpose — borrow ideas as needed.

Community desktop / all-in-one builds

Survey 2026-09-05～09-06; star counts are snapshots, judge activity by Release frequency

dataelement/dsh-desktop

≈4244★ · Electron

The community project closest to a commercial product: 6-language website, signed macOS + signed Windows builds, .dshpreset preset packages, phone pairing, Safe Mode, diagnostic recovery. Most complete spec.

Compared with our green build: a "heavy-delivery" product path with the most complete spec (cross-platform + code signing + 6-language site), for users who value commercial-grade polish.

myYangyunfan/dsh_desktop

≈637★ · Tauri 2

The most feature-complete Chinese community build: bundled offline everything, self-healing "guardian waterfall", desktop pet / balance widget, GitHub/Gitee dual-source sha256-verified updates. Closest to our positioning.

We emphasize "zero footprint + travel with the folder"; it emphasizes "all-inclusive + enhanced interaction".

anywhere-labs/deepseek-harness-desktop

New · active

Electron-based, actively tracking upstream rc; composes desktop capabilities (window / tray / terminal / updates) via Cordis plugin lines, towards "zero-fork" upstream following.

More conservative upstream following, suited to developers who value an untouched core and minimal divergence.

citrusli2026/dsh-desktop (dsh-desktop.com)

v0.1.2-rc.1.shell.5 · macOS/Windows/Linux

A newer community shell (Electron) following the official stance — "just bring Harness to the desktop, don't build another product". Bundles Node, defaults to a separate data dir ~/.dsh-desktop.

Isolated from the official CLI's data; full cross-platform support.

ningbainb/deepseek-harness-desktop

v2.6.0 · Windows · BSD-3

A Windows AI-coding bundle: Task Board, Git graph, right-side file panel, Skills library, Codex integration — leaning toward a "developer workbench".

More feature stacking for heavy developers; larger and heavier to ship.

libi/dsh-desktop

Electron · follows upstream

Another Electron/TS shell: auto-launches the DSH backend, detects a usable port, tray & window management, auto build/publish following upstream. Same family as this kind of shell.

Similar approach; overall positioning close to citrusli.

Distinctive bundled plugins

All are pure plugins — no official files are modified; restart the service after install

🧠 Ancestor Memory

Sinks conversation key facts into SQLite; recalls and injects them into the system prompt next time — cross-session memory, with session grouping and batch cleanup.

📜 User Rules Injection

Write personal preferences / code style / communication requirements in markdown; auto-injected into the system prompt every conversation.

↩️ Session Rollback / Import

Roll back a "poisoned" session to a healthy turn; import session ZIP / JSONL, reciprocal to the official export.

🧾 Usage Stats

Per-message "tokens / estimated cost" plus aggregated usage.

🖼️ Background Motion

Play videos from a local folder as the WebUI background (picture + sound).

🤖 Ollama Integration

Auto-detect a local Ollama service and connect; pick an Ollama model right from the model selector.
