說明：綠色便攜與「全內建整包 / 官方 CLI」是三條互補路線，沒有絕對優劣。本綠色版的核心取捨是——更輕、更乾淨、更可遷移，聚焦 Windows 便攜使用者；犧牲了跨平台與程式簽名等「重交付」能力。社群專案的 Guarded / 安全模式、Task Board 等亮點未刻意復刻，可按需參考移植。

調研 2026-09-05～09-06，star 為調研當天快照，活躍度以 Release 頻率為準

dataelement/dsh-desktop

≈4244★ · Electron

社群最接近「商業成品」：六語種官網、mac 簽名 + Win 程式簽名、.dshpreset 預設包、手機配對、Safe Mode、診斷復原。規格最完整。

對照本綠色版：它走的是「重交付」的產品化路線，規格最完整（跨平台 + 程式簽名 + 六語種官網），適合看重「商業成品級規格」的使用者。

myYangyunfan/dsh_desktop

≈637★ · Tauri 2

中文功能最全的社群版：內建全套離線、守護瀑布自癒、桌面寵物 / 餘額小工具、GitHub/Gitee 雙源 sha256 校驗更新。定位與我們最近。

本綠色版更強調「零污染 + 隨包遷移」，它強調「全內建 + 桌面寵物等增強互動」。

anywhere-labs/deepseek-harness-desktop

較新·活躍

基於 Electron，社群持續跟進上游 rc；以 Cordis 外掛行列組合桌面能力（視窗 / 托盤 / 終端 / 更新），偏向「零 fork 跟隨上游」。

跟隨上游更保守，適合重視「核心原樣 + 少分叉」的開發者。

citrusli2026/dsh-desktop（dsh-desktop.com）

v0.1.2-rc.1.shell.5 · macOS/Windows/Linux

官方形態新出的社群桌面殼（Electron）：「只把 Harness 帶到桌面，不另做一套」。內建 Node、預設獨立數據目錄 ~/.dsh-desktop。

與官方命令列數據隔離、互不干擾；跨平台三端全支援。

ningbainb/deepseek-harness-desktop

v2.6.0 · Windows · BSD-3

Windows AI 程式設計整包：Task Board 任務看板、Git 圖譜、右側檔案面板、Skills 技能庫、Codex 接入，偏向「開發者工作台」。

功能堆疊更強，面向重度程式設計使用者；體積更大、更重交付。

libi/dsh-desktop

Electron · 跟隨上游

另一套 Electron/TS 桌面殼：自動拉起 DSH 後端、識別可用連接埠、托盤與視窗管理、跟隨上游自動建置發布。結構與此類殼一致。

思路同類，整體定位與 citrusli 相近。

特色外掛

全部為純外掛，不修改官方檔案；安裝後重啟服務生效

🧠 祖宗記憶庫

對話關鍵資訊沉澱到 SQLite，下次自動召回注入 system prompt，跨會話保持記憶；支援會話分組與批次清理。

📜 使用者規則注入

編寫個人偏好 / 程式風格 / 溝通要求的 markdown，每次對話自動注入 system prompt。

↩️ 會話回退 / 匯入

會話被工具崩潰「毒化」時回退到健康回合；會話 ZIP / JSONL 匯入與官方匯出互逆。

🧾 用量統計

每條訊息的「本次 token / 預估費用」+ 彙總用量。

🖼️ 背景影畫

本機目錄影片作為 WebUI 背景播放（畫面 + 聲音）。

🤖 Ollama 接入

自動識別本機 Ollama 服務並接入，模型選擇器直接選 Ollama 模型。
