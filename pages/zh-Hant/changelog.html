中文 | English

新增功能

  • 插件管理「搜索」改为纯 npm 来源，并排除 `@deepseek-ai/*` 官方内置插件（只列第三方可装项）
  • npm 搜索结果为前 30 条补充「核心兼容」判定：预估兼容 / 可能不兼容 / 不明
  • 已安装插件列表新增「兼容」列（读本地产物判定，无需联网）
  • 无核心依赖的插件视为「预估兼容」（不依赖官方核心包，不受核心版本变化影响）
  • 推荐列表：npm 源项显示真实版本号 + 兼容状态；GitHub 源项显示「不明」
  • 固定作用域包 `@xxx/yyy` 拉取 manifest 的 404 问题

修复

  • 移除插件后按钮持续禁用的卡死问题（补回忙碌状态复位）
  • 去除搜索结果「分类」列后，来源列读取错位导致 GitHub 插件误装为 npm 的问题
  • 推荐列表支持 npm 版 dsh market（包名 dshmarket），安装更快更稳

界面调整

  • 插件管理窗口加宽至与主启动器同宽（1160），右侧搜索结果列更宽裕
  • 搜索结果去掉「分类」列，版本列加宽以容纳兼容状态文本
  • 按钮顺序：「加载推荐」在前，「搜索npm插件」在后

版本更新

  • GREEN_VERSION: 1.0.36 → 1.0.37

升级建议

  • 绿色版覆盖安装即可

New Features

  • Plugin management "Search" now uses pure npm source and excludes `@deepseek-ai/*` built-in official plugins (only third-party installs are listed)
  • npm search results (first 30) are tagged with a "core compatibility" estimate: Estimated Compatible / May Be Incompatible / Unknown
  • Installed plugins list gains a "Compat" column (evaluated from the local install, no network needed)
  • Plugins with no core dependency are treated as "Estimated Compatible" (not bound to official core version changes)
  • Recommended list: npm-sourced items show the real version + compatibility status; GitHub-sourced items show "Unknown"
  • Fixed 404 when fetching manifests for scoped packages `@xxx/yyy`

Bug Fixes

  • Fixed buttons staying disabled after removing a plugin (busy state not reset)
  • Fixed source-column index regression after removing the "Category" column, which caused GitHub plugins to be misinstalled as npm
  • Recommended list prefers the npm build of dsh market (package `dshmarket`), faster and more reliable to install

UI Adjustments

  • Plugin manager window widened to match the main launcher width (1160), giving the search results column more room
  • Removed the "Category" column from search results; widened the version column to fit compatibility tags
  • Button order: "Load Recommended" first, "Search npm Plugins" after

v1.0.36 2026-09-10

中文 | English

重要更新

用量统计：价格表跟进官方最新调价与模型改名

  • DeepSeek 官方自 2026-09-10 12:00（北京时间）起下调 Flash 系列价格：输入缓存命中 0.10 → 0.04、未命中 3.0 → 2.0、输出 9.0 → 8.0（元 / 每百万 tokens，均为高峰时段价；空闲时段为半价）
  • 当前在售主力模型 id 是 `deepseek-flash`（= DeepSeek-V4.1-Flash，1M 上下文 / 384K 最大输出 / 支持图片）；旧的 `deepseek-v4-flash` 与 `deepseek-v4-flash-vision-exp` 已退役，请求仍受理但由 V4.1-Flash 服务、按 Flash 价计费
  • `deepseek-v4-pro` 自 2026-09-14 12:00（北京时间）起也整批路由到 V4.1-Flash 并按 Flash 价计费
  • 修复费用估算偏高：旧价格表的键名是已退役的 id，真实会话使用的 `deepseek-flash` 查不到单价、一直落到兜底价（比新价高：未命中 +50%、命中 +150%、输出 +12.5%）
  • 价格表存储键升级（`prices.v3` → `prices.v4`），确保浏览器里缓存下来的旧价格表不会盖住新默认值；「设置 → 用量统计」内仍可手工改价并「恢复默认」

会话回退 / 会话导入：适配 dsh 0.1.5 会话格式 v3

  • 会话回退（dsh-session-rewind）、会话导入（dsh-session-import）、用量统计（dsh-usage-stats）统一适配新版 dsh 的 v3 会话存储格式，并对旧格式保持跨版本容错

启动器：dsh 更新通道增加镜像滞后兜底

  • 国内镜像版本落后于官方时自动回退官方源，官方源失败自动重试，避免"镜像还没同步就更新不了"

修复

  • 用量统计费用估算取不到当前模型单价而系统性偏高（见上）
  • 发布页 SEO：hreflang 对齐 ISO 3166-1 Alpha 2（zh-CN / zh-TW）、各语言子目录 robots.txt 指向各自 sitemap、新增 sitemap.txt 纯文本兜底
  • 更新日志页面纯文本行被多余 `` 包裹

版本更新

  • GREEN_VERSION: 1.0.35 → 1.0.36

升级建议

  • 绿色版覆盖安装即可；覆盖后到「设置 → 用量统计」确认价格表已是新版（默认即最新，无需手动修改）

Highlights

Usage stats: price table updated for the latest official pricing and model rename

  • DeepSeek cut Flash-series prices effective 2026-09-10 12:00 (Beijing time): cache-hit input 0.10 → 0.04, cache-miss input 3.0 → 2.0, output 9.0 → 8.0 (CNY per 1M tokens, all peak-hour rates; off-peak is half)
  • The current flagship model id is `deepseek-flash` (= DeepSeek-V4.1-Flash, 1M context / 384K max output / vision capable); the legacy ids `deepseek-v4-flash` and `deepseek-v4-flash-vision-exp` are retired — requests are still accepted but served by V4.1-Flash and billed at the Flash price
  • From 2026-09-14 12:00 (Beijing time), `deepseek-v4-pro` is also routed entirely to V4.1-Flash and billed at the Flash price
  • Fixed systematically overestimated cost: the old price table was keyed by retired ids, so the model actually used (`deepseek-flash`) never matched and silently fell back to the default row (higher than the new price: miss +50%, hit +150%, output +12.5%)
  • The price-table storage key is bumped (`prices.v3` → `prices.v4`) so a stale table cached in the browser can no longer shadow the new defaults; the table is still editable with a "restore defaults" button under Settings → Usage Stats

Session rewind / session import: adapted to dsh 0.1.5 session format v3

  • Session Rewind (dsh-session-rewind), Session Import (dsh-session-import) and Usage Stats now read the new v3 session storage format, while staying tolerant of the older formats

Launcher: mirror-lag fallback for the dsh update channel

  • When the domestic mirror lags behind the official release, the launcher now falls back to the official source and retries, so an unsynced mirror no longer blocks updates

Bug Fixes

  • Usage-stats cost estimate was systematically too high because the current model id had no price row
  • Site SEO: hreflang aligned to ISO 3166-1 Alpha 2 (zh-CN / zh-TW), each language subdirectory's robots.txt points to its own sitemap, and a plain-text sitemap.txt fallback was added
  • Changelog page wrapped plain-text lines in a redundant `` tag

Version Bump

  • GREEN_VERSION: 1.0.35 → 1.0.36

Upgrade Notes

  • Green edition: overwrite install is sufficient. After overwriting, open Settings → Usage Stats to confirm the new price table is in place (defaults are already current; no manual edit needed)

v1.0.35 2026-09-08

中文 | English

新增功能

右键菜单功能与排序统一

  • 侧栏文件右键菜单与文件浏览器的右键菜单功能、排序完全对齐
  • 文件行菜单（6 项）：以官方 @ 引用插入 → 插入路径 → 插入内容 → 另存为 → 复制相对路径 → 复制绝对路径
  • 目录行菜单（3 项）：插入路径 → 复制相对路径 → 复制绝对路径

文件浏览器新增

  • 另存为：调用宿主端新增 /download 路由取完整文件（单文件上限 32MB），优先原生「另存为」对话框，不支持时回退浏览器下载
  • 复制相对路径 / 复制绝对路径（原「复制路径」更名为「复制绝对路径」）

侧栏插入能力补齐

  • 新增「插入路径到输入框」「插入内容到输入框」菜单项，与文件浏览器一致
  • 主页域名更新为独立站点 https://dsh-green.website/

修复

  • 侧栏连续插入路径/内容时，偶发插入到文件预览器（而非会话输入框）的问题
  • 侧栏与文件浏览器右键菜单功能不一致

技术架构

  • 侧栏插件独立注册官方 conversation.input.left slot 捕获输入机通道（inputActions/input），不再依赖文件浏览器注入的全局变量，两插件互不依赖
  • 插入走三级降级：inputActions.setDraft → 官方输入机 bail → DOM fallback

版本更新

  • GREEN_VERSION: 1.0.34 → 1.0.35

升级建议

  • 绿色版覆盖安装即可

New Features

Unified right-click menus (sidebar & file browser)

  • The sidebar file list and the file browser now share identical right-click menu actions and ordering
  • File row (6 items): official @ reference → insert path → insert content → save as → copy relative path → copy absolute path
  • Directory row (3 items): insert path → copy relative path → copy absolute path

File browser additions

  • Save As: new host /download route streams the full file (32MB per-file limit); uses the native "Save As" dialog when available, falls back to browser download
  • Copy Relative Path / Copy Absolute Path (the old "Copy Path" is renamed "Copy Absolute Path")

Sidebar insertion capabilities

  • Added "Insert Path to Input" and "Insert Content to Input" menu items, aligned with the file browser
  • Homepage URL updated to the standalone site https://dsh-green.website/

Bug Fixes

  • Fixed sidebar insertion occasionally landing in the file previewer instead of the conversation input after repeated inserts
  • Fixed menu inconsistency between sidebar and file browser

Technical Architecture

  • The sidebar plugin now registers the official conversation.input.left slot by itself to capture the input machinery (inputActions/input), no longer relying on globals injected by the file browser — the two plugins are fully independent
  • Insertion uses a 3-level fallback: inputActions.setDraft → official input bail → DOM fallback

Version Bump

  • GREEN_VERSION: 1.0.34 → 1.0.35

Upgrade Notes

  • Green edition: overwrite install is sufficient
