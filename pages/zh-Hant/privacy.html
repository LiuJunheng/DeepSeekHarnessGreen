隱私政策

最後更新：2026-09

一、我們不收集你的個人數據

DeepSeek Harness 桌面綠色整合版啓動器是一個開源的綠色便攜工具，運行在你的本地電腦上。它不收集、不上傳、不存儲任何個人身份信息（PII）。

啓動器需要聯網的唯一場景是：

  • 首次安裝環境時下載便攜 Node / Python / dsh 運行時文件
  • 啓動器自身檢查更新（調用 GitHub / Gitee 的公開 Release API）
  • 官方 dsh 運行時向你自己配置的 AI 模型服務發送 API 請求（完全由你控制）

以上網絡請求都不附帶你的個人信息，也不被第三方用於追蹤。

二、發佈網站與 Google AdSense

本項目的發佈網站（dsh-green.website）託管在 Cloudflare Pages 上。

如果我們未來在本網站上啓用 Google AdSense 來覆蓋運營成本，你需要了解：

  • Google AdSense 可能會使用 Cookies 在你的設備上存儲信息，用於展示個性化廣告。
  • Google 可能會分析你訪問本網站的頁面、停留時間等非個人身份化的瀏覽數據，以決定展示哪些廣告。
  • Google 的數據處理遵循 Google 隱私政策。
  • 你可以通過瀏覽器設置清除、禁用或限制 Cookies，也可以使用廣告攔截器來阻止 AdSense 廣告。

三、GitHub Pages 日誌

GitHub Pages 可能自動記錄訪問日誌（IP 地址、User-Agent、請求時間戳），用於安全和故障診斷。我們無法直接訪問或修改這些日誌。具體做法請參考 GitHub Pages 文檔。

四、不做什麼

  • 我們不會把你的數據賣給第三方。
  • 我們不會把你的數據與任何廣告商共享。
  • 我們不會在啓動器裏植入追蹤代碼。
  • 我們不會要求你註冊賬戶或提交電子郵箱。
