快速上手

  1. 解壓下載的綠色 zip 到任意目錄。
  2. 雙擊 DSH_Launcher.exe（或 start.bat）。
  3. 點【安裝環境】：自動下載便攜 Node → 安裝 dsh → 補齊內置 Python（首次需要聯網）。
  4. 點【啓動服務】→ 自動打開獨立桌面窗口（也可切到網頁窗口）。
  5. 在網頁裏設置 → 模型 → 填入 DeepSeek API Key，並選擇工作區，即可開始。

常見問題

提示找不到 Python？

多爲內置便攜 Python 下載失敗（網絡問題）。按 start.bat 提示手動安裝 Python 3 並勾選 “Add to PATH” 兜底。

下載 Node / 安裝 dsh 慢？

在界面設置把鏡像源切到「國內」或「官方」再試（默認已是國內優先）。

端口被佔用？

設置裏改端口（如 3090）後保存重啓服務。

網頁打不開？

查看 runtime/server.log；確認防火牆沒攔 127.0.0.1。

綠色版更新失敗？

更新程序會彈窗給出手動下載地址（GitHub / Gitee 發佈頁 + 直鏈），解壓後覆蓋到程序根目錄—注意不要覆蓋 config.json 與 runtime/。
