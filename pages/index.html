快速上手

  1. 解压下载的绿色 zip 到任意目录。
  2. 双击 DSH_Launcher.exe（或 start.bat）。
  3. 点【安装环境】：自动下载便携 Node → 安装 dsh → 补齐内置 Python（首次需要联网）。
  4. 点【启动服务】→ 自动打开独立桌面窗口（也可切到网页窗口）。
  5. 在网页里设置 → 模型 → 填入 DeepSeek API Key，并选择工作区，即可开始。

常见问题

提示找不到 Python？

多为内置便携 Python 下载失败（网络问题）。按 start.bat 提示手动安装 Python 3 并勾选 “Add to PATH” 兜底。

下载 Node / 安装 dsh 慢？

在界面设置把镜像源切到「国内」或「官方」再试（默认已是国内优先）。

端口被占用？

设置里改端口（如 3090）后保存重启服务。

网页打不开？

查看 runtime/server.log；确认防火墙没拦 127.0.0.1。

绿色版更新失败？

更新程序会弹窗给出手动下载地址（GitHub / Gitee 发布页 + 直链），解压后覆盖到程序根目录—注意不要覆盖 config.json 与 runtime/。
