# 用户自定义规则

在此编写你的个人偏好、代码风格、沟通要求等规则。
每次对话开始时, 以下内容会作为系统提示词注入。

> 💡 提示: 用 markdown 格式, 保持简洁 (建议不超过 16000 字符)。
> 修改后保存, DSH 会在下次请求时自动读取最新内容 (autoReload=true)。

---

## 代码风格

- 变量名用英文全称, 不要简写 (如 button 不要写 btn)
- Python 项目尽量用最少依赖, 优先相对路径安装
- Python 项目要考虑 Windows, 提供 bat 一键运行脚本

## 沟通偏好

- 回复用中文
- 每次改动后记得同步更新 md 文档

## 其他要求

- 文案包装优先用三国历史典故 (可选)
